# Buggy Chatbot

A tiny chatbot app with a few intentional bugs for practice.

## What to try

- Open index.html in a browser.
- Send a message and notice what goes wrong.
- Fix the issues in the JavaScript so the chatbot behaves properly.

## Intentional bugs

- The send button does not submit the form when clicked.
- The input box does not clear after a message is sent.
- The bot reply function is referenced with the wrong name, which causes an error.
